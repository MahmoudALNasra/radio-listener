# XTL 2500 direct audio — chat summary (2026-10-08, PC "abrah")

Condensed record of the Cursor agent session that produced
[`xtl2500-build-guide.pdf`](xtl2500-build-guide.pdf). Chats do not sync between PCs,
so the decisions and facts are written down here. Not a verbatim transcript.

## What was decided

| Topic | Decision |
|-------|----------|
| Setup type | **Fixed indoor receive station**, not a vehicle. Radio receives, PC transcribes (Vosk) and fires keyword triggers. Radio never needs to transmit for this. |
| Audio path | **Option B** from `xtl2500-direct-audio.md`: rear J2 **pin 21** (RX filtered audio, fixed level) + **pin 14** (ground) → HLN6863B housing → 2.2 µF bipolar cap in series on the pin‑21 wire → 3.5 mm TRS → ground‑loop isolator → UGREEN USB sound card **red** jack → PC. No cabin mic, no speaker needed. |
| Option A (speaker‑wire LOC) | Kept only as fallback. User does not care about the speaker. |
| Power | Radio **cannot** run from USB. Station uses a **13.8 V DC supply, 20 A+** (Samlex SEC‑1223 class) + Motorola **HKN4191C** power cable. HLN6863B red fused ignition lead goes to the supply **(+)** permanently so the radio sees "ignition on". |
| Antenna | New part for the station: **800 MHz mag‑mount with mini‑UHF plug** on a steel plate near a window (outdoor base antenna + mini‑UHF→N adapter if reception is weak). |
| Software | Unchanged: `device/listener.py` with `input_device` pointed at the USB Audio Device. Station PC should autostart the listener (Task Scheduler / systemd). |

## Questions asked and answers given (in order)

1. **"Create a PDF of `xtl2500-direct-audio.md` for printing."** → Print‑styled PDF made (Edge headless from HTML).
2. **"Visualization of the parts and the radio connected."** → Chain diagram. User clarified: *"I don't care about the speaker; the PC listens directly to the radio, the radio is the input."* → Diagram redone with no speaker path.
3. **"Images of the parts."** → Reference images made. User then supplied **real photos of their radio** (front + rear). Rear photo confirms: antenna (mini‑UHF) far left, 2‑pin power socket right of the heat sink, 26‑pin **J2** far right.
4. **"What is J2 pin 21 / 14 — what do I buy?"** → J2 is the rear 26‑hole socket; 21 and 14 are two holes in it. You do not buy "a pin 21": buy the **HLN6863B** plug that fits J2 plus two **crimp pins** (3980034F01 / F04, or eBay "HLN6961 XTL APX accessory connector pins") and push them into holes 21 and 14.
5. **"After the HLN6863B, what does it connect to?"** → HLN6863B → cap → 3.5 mm cable → isolator → USB sound card red jack → PC.
6. **"How does the capacitor connect to it?"** → It is **spliced into the pin‑21 (signal) wire** between the HLN6863B and the 3.5 mm plug; the pin‑14 ground wire runs straight through. Bipolar = no polarity.
7. **"Does the radio get power from USB?"** → No. Own 12–13.8 V supply; USB only powers the sound card.
8. **"I want a power supply too."** → Spec from Motorola data sheet: 0.85 A standby, 3.2 A receive, 12 A transmit (35 W). Recommend 13.8 V / 20 A+ and HKN4191C (12 AWG, 20 A fuse). Not HKN4137 (15 A).
9. **"I don't get it — more detail, make a PDF with images."** → `xtl2500-build-guide.pdf`: one‑picture overview (power chain vs audio chain), user's rear photo with numbered sockets, parts A–J with photos / search text / prices / "connects to", 13‑row connection map, cable‑build drawing, 13 numbered steps, troubleshooting, checklist.
10. **"This is a station, not a car; radio receives → audio → words → triggered on command."** → Guide revised: supply is permanent, antenna added as part J, speaker optional, trunked‑registration note (radio may TX short bursts on its own → keep 20 A and antenna connected), autostart note.
11. **"Upload the guide and chat to the repo."** → Commit `77b630f`.
12. **(2026‑10‑10) "Can we have a GIF or image to support each step?"** → PDFs cannot animate, so every one of the 13 steps got a still figure: exact drawings for the wiring steps, crops of the user's radio photos with arrows for the plug‑in steps, a Windows Sound mockup, and the real `config.json` keys. Photos `step-*.jpg` added to `docs/xtl2500-parts/`.

## Key facts (verified during the session)

- J2 pinout (XTL install manual Table 3‑3 / W9CR wiki): **21 = RX FILT AUDIO**, **14 = GRND**, 20/26 = speaker ± (never ground), 25 = ignition, 24 = SW B+, 9 = BUSY, 13 = CHAN ACT.
- HLN6863B = Motorola "mid‑power rear ignition cable" for XTL 1500/2500/5000 and APX; 26‑pin housing pre‑wired for ignition + speaker; $39–44 new, ~$12 used.
- HKN4191C = 10 ft, 12 AWG, 20 A inline fuse, 2‑pin plug; current revision of HKN4191A/B.
- UGREEN 30724 (B01N905VOY): red jack = mono mic‑level input, works on Windows and Pi without drivers. Start Windows input level ~30 %, mic boost 0 dB.
- Cable Matters ground‑loop isolator = model 500057‑BLK (B08G9J74VX).
